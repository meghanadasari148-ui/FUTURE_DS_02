# Customer Retention & Churn Analysis

## 📌 Project Overview
This project analyzes customer churn data to identify churn patterns, retention drivers, and customer lifetime trends for a subscription-based business.

## 🎯 Objective
- Analyze customer churn behavior
- Identify retention drivers
- Study customer lifetime trends
- Generate actionable business recommendations

## 🛠️ Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## 📂 Dataset
- Telco Customer Churn Dataset

## 📊 Analysis Performed
- Data Cleaning
- Missing Value Analysis
- Churn Rate Analysis
- Contract Type Analysis
- Internet Service Analysis
- Payment Method Analysis
- Senior Citizen Analysis
- Correlation Analysis
- Interactive Dashboard

## 📈 Key Insights
- Month-to-month customers have the highest churn.
- Long-term contracts improve customer retention.
- Fiber Optic customers experience higher churn.
- Contract type and tenure strongly influence customer retention.

## 💡 Recommendations
- Encourage long-term contracts.
- Improve Fiber Optic service quality.
- Offer loyalty rewards.
- Target high-risk customers with personalized retention offers.
